Player Aspects Directory Configure individual player features

Enable or disable specific features added to the video player. Each aspect dynamically inherits theme appearance and locates its optimal slot.

layers Codec & Realtime Bitrate Floating Tags
Displays adaptive floating tags showing video codec, resolution, special video flags (Dolby Vision, HDR10+, HLG, BT.2020), audio channels, and live bitrate when player elements are active. Clicking tags in the player allows users to toggle tags and styles per session.
When unchecked, non-admin users only see "Transcoding" without raw reason descriptions or hardware engine info.
Global Tag Permissions (Admin Policy):
speed Playback Speed Controller
Adds an adaptive speed selector button and themed popup sheet (0.5x, 0.75x, 1x, 1.25x, 1.5x, 1.75x, 2x, custom). Automatically updates the native video element playback rate without distortion.
photo_camera Quick Frame Snapshot
Captures clean, full-resolution video screenshots at the current frame without OSD clutter. Offers instant clipboard copy and file download with visual shutter animation.
query_stats Stream Stats & HUD Overlay
Shows a sleek, glassmorphic HUD card showing real-time player diagnostics: resolution, video codec, audio channels, buffer health, playback bitrate, and dropped frames.
graphic_eq Adaptive Dialogue & Audio Boost
Utilizes Web Audio API GainNode and DynamicCompressor to safely boost quiet dialogue and normalize loud explosions directly in the browser client.
